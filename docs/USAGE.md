# Clasp 拾贴

Windows 本地剪贴板管理器，支持文字、链接、图片和文件历史。适用于 Windows 10/11 x64，需要 .NET Framework 4.8。

解压后双击 Clasp.exe 即可运行，无需安装。下载与反馈：https://github.com/j1903059993/Clasp-Releases

## 开始使用

双击 `Clasp.exe`。程序会在系统托盘常驻，从启动后的下一次复制开始记录；不会导入启动前的剪贴板。

- 默认 **Alt + V**：呼出 / 收起贴在屏幕最底部的面板。面板占满当前屏幕工作区宽度，高度尽量压缩。可在「设置 → 唤醒快捷键」录入组合键，会立即检测占用；也可点击「检测冲突」重新检测。保存后立即生效，重启保留。点击「恢复默认」可直接选择 Alt + V，无需按下可能被其他应用占用的组合键。冲突以红色提示，原设置保持不变，不会自动换键。修改其他程序的快捷键后，回来重新检测并保存。程序不能直接取得占用快捷键的进程名称。
- 唤醒后右上角的关闭按钮、Esc 或再次按下唤醒快捷键均可收起面板。
- 复制文字、网页链接、图片、文件后，记录会自动出现在面板中。卡片标题来自内容本身：文字取第一行、链接取域名、文件取文件名；图片直接显示画面，不另起标题。左上角是来源应用的图标。
- 历史列表只允许左右滑动，没有竖向滚动条。鼠标滚轮会横向移动卡片。
- 图片卡片按完整容貌等比显示，不裁切；预览仍可缩放查看细节。
- 单独的 HTTP、HTTPS 和 www 开头的网址会显示为蓝色下划线超链接，点击域名或网址即可用系统默认浏览器打开；www 地址打开时补全 HTTPS。右键也可选择打开。
- 点卡片上的 **☆**：真正固定在所有普通历史前面；再次点击取消。右键可调整置顶顺序。
- 搜索框默认是短胶囊，点一下或开始输入后展开；搜索和全部分类在中间，暂停、设置、关闭在最右侧。**Ctrl + F** 也会展开并聚焦搜索。多个关键词按“同时包含”匹配。
- **← / →**：选择卡片（搜索框为空时）。**Enter / 单击卡片**：回到原应用粘贴。
- **Shift + Enter**：文字按纯文本粘贴。**Alt + 1 … 9**：粘贴前九项。
- **Space**：预览完整内容（搜索框为空或未聚焦时）。**Esc**：收起。
- 图片预览支持滚轮缩放，以鼠标位置为中心；按住左键拖动查看放大后的内容，双击或点击「适应窗口」恢复全图。工具栏提供加减缩放和 100%，最大支持 1600%。截图和备份中的图片文件均适用。
- 内容预览右上角提供最大化／还原按钮，也可双击标题栏切换。图片预览无额外底色，底部缩放操作居中；适应窗口模式会随窗口尺寸调整图片。
- 右键卡片：粘贴、仅复制、置顶、预览或删除。
- 设置中可以选择或填写存储目录，点击「迁移并使用」将历史、图片和文件副本复制到新目录并校验，旧目录保留为备份。选择一个独立的空文件夹，避免覆盖其他数据。修改后立即生效，重启仍使用该目录。
- 设置中也可以调整普通历史上限、打开数据目录、清除普通历史。暂停状态会保留到下次启动。
- 完全退出：系统托盘图标 → 退出拾贴。
- **设置 → 常规 → 开机自启**：打开后在登录当前 Windows 账户时自动运行，并静默驻留托盘；关闭后移除拾贴的启动项。默认不主动开启，不需要管理员权限。
- 自启引用当前 exe 的完整路径；移动程序后，需要从新位置重新开启该设置。若 Windows「启动应用」或任务管理器禁用了该项，设置页会提示并提供系统设置入口。系统可能延后启动，此功能不是开机前的系统服务。
- 设置页按「常规／外观／存储／关于」分类，修改透明度和动画在外观页，修改存储路径在存储页。
- 「设置 → 外观 → 面板透明度」默认 58%，范围 10%–100%。百分比越大，越能透出下方应用或桌面的颜色；越小，白色玻璃叠层越浓，不会增加黑色遮罩。玻璃会柔化背景，卡片中的文字和图片保持清晰。
- 「设置 → 打开与收起动画」提供底部收纳（默认）、底部滑动、轻柔淡入、轻盈缩放和无动画，速度可选快 / 标准 / 舒缓，选择后自动保存。打开收起带动真实毛玻璃，过程中透明度与展开后一致。系统关闭界面动画时不播放。

## 数据与边界

- 默认存储：exe 旁的 `Data` 文件夹。`Images` 保存实际 PNG 图片，`Files` 保存文件副本，`history.json` 保存历史记录。自定义路径保存在 exe 旁的 `settings.json`。移动默认便携版时连同 Data 一起移动；自定义目录使用绝对路径，移动后可在设置中重新选择。备份时先退出程序，再复制整个数据文件夹。
- 文字、HTML、RTF 和文件路径保存在本地 JSON；图片另存 PNG。无账号、无上传、无遥测。目前数据没有加密，不建议复制保留密码或令牌；可用“暂停记录”。尊重应用提供的剪贴板历史排除标记，但无法自动识别所有敏感内容。
- 默认保留 500 条普通历史，置顶不受上限影响。重复内容更新最近复制时间，置顶顺序不变。
- 原子写入，并保留一份历史备份供故障恢复。“清除全部普通历史”也会更新恢复备份，避免已清除的普通记录残留。
- 单条文字上限 100 万字符；图片上限 2500 万像素、20 MB。超限不会保存。收到复制通知后立即读取，剪贴板被占用时每 80 ms 重试，最多 8 次。
- 文件记录现在自动保存副本，粘贴优先使用副本，原文件移动或删除不影响已成功备份的记录；文件夹与空目录也会保存。相同路径再次复制会保留当时的新版本。旧记录中的可用文件会在升级后补做一次备份。
- 单次文件备份最多 200 MB、10000 个项目；磁盘根目录、符号链接及存储目录自身不自动备份。原件丢失、权限不足或超限时明确标记「未备份」，仍可在原路径有效时粘贴。预览中列出原始路径和备份路径，右键可打开备份目录。剪切文件按复制语义重用，不重复执行移动。
- 图片卡片直接显示本地图片，按比例完整容纳、不裁切；预览显示完整内容。从资源管理器复制单张 PNG、JPEG、BMP、GIF、TIFF 或 ICO 文件时，也直接显示缩略图并出现在图片分类，同时保留文件粘贴语义。兼容历史截图的全零透明通道，保留正常半透明图片；截图粘贴同时提供 PNG 和兼容位图格式。已有异常图片读取时修复，不覆盖其原始文件。
- 迁移时暂缓记录并在结束后读取最新剪贴板状态；失败时继续使用旧目录，可能在目标中保留不完整的迁移副本。程序对当前数据目录加独占锁，避免多个实例同时写入。
- 原应用焦点恢复失败时会保留内容到剪贴板并提示手动 Ctrl + V。Windows 权限限制可能阻止向管理员应用自动粘贴；无需以管理员身份启动本程序。
- 本版没有云同步、OCR 或自定义分组；开机自启仅在用户开启设置后注册。
- 适用于 64 位 Windows 10/11、.NET Framework 4.8。界面使用系统 DPI 感知，多屏按目标应用所在屏幕定位；不同缩放比例的屏幕需要进一步实机验证。

## 升级与卸载

升级前从托盘退出程序，保留原有 Data 文件夹和 settings.json，再替换应用文件。使用自定义数据目录时，请同时保留该目录。建议先备份数据。

卸载前在设置中关闭开机自启，再从托盘退出并删除程序目录。若要保留历史，请先复制 Data 或自定义数据目录；删除数据目录会删除其中的历史和文件副本。
